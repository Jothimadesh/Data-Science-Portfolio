# 🛒 Retail Transaction Analytics Engine

## 🎯 Business Problem
Retailers need to track revenue trends, 
KPIs and profit margins in real time.
This dashboard provides instant visibility 
into sales performance across categories, 
regions and products.

## 📊 Dataset
- **Source:** Kaggle – Sample Superstore
- **Rows:** 9,977 transactions
- **Columns:** 13 features
- **Domain:** Retail & E-commerce

## 🚀 Live Demo

## 📈 Key Business Insights
1. Technology is highest revenue → $836,154
2. West region leads → $725,256 in sales
3. Phones and Chairs are top sub-categories
4. Furniture has low profit → Only $18,422
5. Discounts above 20% cause losses
6. California is #1 state → $457,576
7. Standard Class is most preferred shipping
8. Consumer segment generates most revenue
